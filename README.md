# Loom

## 简介

一个学习项目，产物是一个可安装的基础组件库。

## 项目背景

这不是一个以生产使用为首要目标的组件库。对想理解前端原理的人来说，直接拿现成实现来用，跳过的正是最该亲手做的部分。它是一个从原生到 React 再到 Next.js 的学习项目，产物是一个可安装的基础组件库；可安装是验收手段，不承诺生产级完备。

从头开发一个组件库，能让我看到之前工作方式的局限，从调用者变成创造者。每做一个组件，都要处理语义、样式、类型、测试、文档和部署；之后再使用成熟产品时，就能从原理上理解它为什么这样设计，而不是只会调用 API。

## 学习路线

1. 用原生 HTML / CSS / JS 实现基础组件，设计组件 API，亲手处理事件、布局、竞态与焦点，并建立测试机制。
2. 迁移到 React，对照原生实现，理解框架接走了哪些复杂度，又引入了哪些限制。
3. 用 Next.js 实现文档站与示例应用，练习 App Router、Server Components、数据获取与部署，同时训练文档书写与示例设计。

## 目标

- 学习路径：原生 → React → Next.js
- 产物一：可安装的基础组件库
  - v0.1 的 9 个组件键盘可用，axe 0 critical
  - 每个组件有单元测试与交互测试
- 产物二：Next.js 文档站与示例应用
  - 文档站：每个组件有独立文档（API + 示例），部署后可访问
  - 示例应用：包含认证、数据库与 CRUD，部署后可访问，用来验证组件库在真实页面中的可用性

## 约束

### 组件范围

- v0.1：Button、Field/Input、Checkbox/Switch、Dialog、Tabs、Menu/Dropdown、Tooltip/Popover、Toast、Combobox/Select（9 个）
- v0.2：Data Table、Date Picker、Command Palette

### 技术与实现

- S1–S4 不引入 React、Tailwind 或现成组件库，先用原生实现
- 不复制现成实现；可以先读 Radix / shadcn 的源码，但必须先完成自己的版本
- 组件库不依赖具体应用；文档站与示例应用只消费组件库，不反向侵入
